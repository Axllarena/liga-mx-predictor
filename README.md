# Liga MX Predictor

Predicting Liga MX match outcomes with Python and machine learning — a data science portfolio project.

## About

This project is my hands-on path into data science and Python, using something I actually care about (Liga MX football) as the subject. I'm a systems engineering student with a background in Java and C, learning Python and applied ML by building this from scratch — starting from raw match data and working toward outcome predictions.
